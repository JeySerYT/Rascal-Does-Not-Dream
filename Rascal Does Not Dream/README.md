# Rascal Does Not Dream

Mai Sakurajima Theme for [PulseSync](https://pulsesync.dev/) (Yandex Music)

> Тема для Яндекс Музыки с персонажем Mai Sakurajima из аниме "Rascal Does Not Dream of Bunny Girl Senpai"

![Banner](assets/metadata/banner.gif)

## Особенности

- Тёмно-синяя цветовая схема
- Анимированный VibeBlock с GIF персонажа
- Кастомный тайтлбар
- Настройки темы (отключение Vibe анимации, GIF)

## Контрибьюторы

- JeySerYT - автор темы

## Установка

1. Скачай последний релиз или собери из исходников
2. Скопируй папку темы в `%APPDATA%/PulseSync/addons`
3. Активируй тему в настройках PulseSync

## Сборка из исходников

```bash
yarn install
yarn build
```

Готовая тема будет в `dist/Rascal Does Not Dream/`
