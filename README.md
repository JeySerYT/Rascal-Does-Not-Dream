# Rascal Does Not Dream <3

Mai Sakurajima Theme for PulseSync

## О теме

Тема для Яндекс Музыки с персонажем Mai Sakurajima из аниме "Rascal Does Not Dream".

## Структура проекта

```
.
├── package.json              # Конфигурация сборки
├── README.md                # Этот файл
├── .gitignore               # Игнорируемые файлы
└── Rascal Does Not Dream/   # Папка темы
    ├── metadata.json        # Метаданные темы
    ├── project/            # CSS и JS
    │   ├── style.css
    │   ├── script.js
    │   └── handleEvents.json
    └── assets/              # Изображения
        ├── mai-vibe.gif
        ├── player.gif
        ├── load.gif
        └── metadata/
            ├── icon.gif
            └── banner.gif
```
