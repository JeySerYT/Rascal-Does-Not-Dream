# Rascal Does Not Dream

Mai Sakurajima Theme for PulseSync (Yandex Music)

## Установка

1. `npm install`
2. `npm run build`
3. Скопируй `dist/Rascal Does Not Dream` в папку аддонов PulseSync

## Команды

- `npm run build` — сборка
- `npm run dev` — dev mode с hot reload
